# Значок Gemini и луна в роликах первого экрана

Ролики сделаны в Gemini, в правом нижнем углу у них полупрозрачная звёздочка-значок.
Здесь — как её убирали (сентябрь 2026). Запуск из этой папки, нужен ffmpeg (путь — в скриптах).

1. `node shape.js <ffmpeg> ролики…` — форма значка по данным: радиус края через 2,5° → `wm-shape.json`.
2. `node fit4.js <ffmpeg> ролики…` — центр, масштаб и непрозрачность по шву → `wm-model.json`.
3. `node curve2.js <ffmpeg> ролик` — для каждого ролика и цвета: непрозрачность A и цвет значка W
   (у рассвета и заката A≈0,28 белый, у роликов по кругу A≈0,6 серый) → вписать в `PER` в `wmlib.js`.
4. `node process.js вход.mp4 выход.mp4 sunrise|dayloop|dusk|nightloop` — кадр за кадром:
   значок вычитается (s = (p − m·A·W)/(1 − m·A)), край заглаживается, ролик собирается заново
   (x264 CRF 17 — на глаз без потерь). Для ночи ещё и луна: в ночном ролике она стоит на месте
   (во все кадры — кусок неба с луной из первого кадра), в конце заката влетающая луна стирается,
   а неподвижная проявляется там же, где стоит в ночи. `moon.js` — проверка: центр луны по кадрам.

Исходники — в «Загрузках» (пути внутри `process.js`); результат кладётся в `assets/video/`,
первые кадры — `ffmpeg -i ролик -frames:v 1 -q:v 2 кадр.jpg`.
