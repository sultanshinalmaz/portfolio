# Бот-приёмщик заявок

Заявки с сайта-портфолио приходят вам в Telegram через этого бота.
Бот делает то, чего сам сайт сделать не может: **видит, с какого аккаунта
пишет человек**. Поэтому именно он:

- проверяет, что пишет человек, а не программа — просит нажать на названный
  знак (🌙 ⭐ 🌴 🕌, знак и порядок каждый раз новые, после трёх ошибок — пауза 10 минут);
- пропускает **одну заявку с одного аккаунта**. На повторную попытку отвечает:
  «Вы уже отправили заявку, дождитесь ответа»;
- присылает заявку вам (@tashbakaa) с именем клиента и ссылкой на его профиль.
  Голосовые пересылает как есть.

Под каждой заявкой у вас кнопка **«✅ Ответил — снять ограничение»**: после неё
клиент снова сможет отправить заявку. Если не нажимать — ограничение снимется
само через 7 дней (`REPEAT_DAYS` в `.env`).

Пока бот не запущен, сайт работает и без него: кнопка «В Telegram» открывает
чат прямо с @tashbakaa с готовым текстом заявки.

## Запуск — 5 минут

1. **Создайте бота.** В Telegram откройте @BotFather → `/newbot` → придумайте
   имя (например, «Заявки SIFR») и ник, который кончается на `bot`
   (например, `sifr_zayavki_bot`). BotFather пришлёт токен.
2. **Впишите токен.** Скопируйте `.env.example` в `.env` и вставьте токен
   в строку `BOT_TOKEN=`. Ник владельца уже стоит: `OWNER_USERNAME=tashbakaa`.
3. **Запустите.** Нужен Node 18 или новее, npm не нужен:

   ```bash
   node telegram/bot.js
   ```

4. **Нажмите «Старт» в боте со своего аккаунта @tashbakaa.** Бот ответит
   «Готово: заявки с сайта будут приходить сюда». Без этого шага Telegram не даст
   боту писать вам первым — заявки будут копиться и придут, когда нажмёте «Старт».
5. **Подключите бота к сайту.** В `assets/js/data.js` впишите его ник без `@`:

   ```js
   bot: 'sifr_zayavki_bot',
   ```

   С этого момента кнопка «В Telegram» на сайте ведёт в бота.
6. **Проверьте.** Напишите боту `/test` — пройдёте путь клиента сами,
   заявка придёт вам же. Со своего аккаунта ограничение «одна заявка» не действует.

## Где держать бота включённым

Бот работает, пока запущен `node telegram/bot.js`. Выключите компьютер —
заявки будут ждать в Telegram и придут, как только бот снова запустится
(Telegram хранит их сутки). Чтобы бот работал всегда, его ставят на недорогой
сервер (VPS) и запускают через `pm2 start telegram/bot.js`.

## Команды владельца

| Команда | Что делает |
|---|---|
| `/test` | пройти путь клиента: проверка → заявка приходит вам |
| `/stats` | сколько заявок всего и сколько ждут ответа |
| `/unblock @ник` | снять ограничение с клиента вручную |
| `/id` (для всех) | показать числовой id — можно вписать в `OWNER_CHAT_ID` |

## Файлы

- `bot.js` — сам бот. Списки «что нужно / сфера / сроки» и названия работ берёт
  из `../assets/js/data.js`, поэтому правки на сайте бот подхватывает сам
  (после перезапуска).
- `.env` — токен и настройки (создаёте сами из `.env.example`, никому не показывайте).
- `data.json` — появится сам: чат владельца и список отправленных заявок.

Проверить разбор заявки без токена: `node telegram/bot.js --test z3-12-rahat`.

## Про WhatsApp

WhatsApp не сообщает сайту, кто пишет, а своего бота в WhatsApp без платного
WhatsApp Business API не сделать. Поэтому для кнопки «В WhatsApp» проверка
«не бот» и «одна заявка» работают **на самом сайте**: заявку можно отправить
один раз с одного устройства (браузера), повторно сайт покажет
«Вы уже отправили заявку, дождитесь ответа». Тот же сайтовый барьер стоит
и перед кнопкой «В Telegram» — бот добавляет к нему проверку по аккаунту.
